# 知脂 · 四测量体脂率估算

**一个从《系统工程概论》大作业衍生的体脂估算小工具。**

最初，这只是一次使用 BP 神经网络预测成年女性体脂率的课程作业。后来，我把训练好的模型做了简单包装，开发成可以在电脑和手机上直接打开的网页，希望家人，以及其他想用简单、快捷的方式初步了解自己体脂率水平的人，都能方便地使用。

只需要**身高、体重、腰围和臀围**四项数据，就可以得到一个体脂率估计值，并查看模型的误差参考和使用限制。不需要购买专业设备，也不需要注册账号。

> **请注意：** 这是学习项目衍生的非医疗工具。结果仅供日常了解身体情况时参考，不能用于诊断疾病，也不能代替 DXA、专业体成分检查或医生的判断。

## 使用方法

1. 打开网页，阅读适用人群说明。
2. 输入身高（cm）、体重（kg）、腰围（cm）和臀围（cm）。
3. 点击「查看体脂率估计」，查看预测值、误差参考与注意事项。

腰围和臀围的测量位置很重要，请尽量按照页面中的示意与说明测量。

## 模型从哪里来？

这个工具基于美国 **NHANES 2017–2018** 调查数据，使用其中 **1,245 名 18–59 岁成年非孕女性**的有效记录，以 **DXA 全身体脂率**作为预测目标。

模型使用四项手工测量数据，并自动计算 BMI、腰臀比、腰高比，共形成 7 个输入特征。预测核心是由 **5 个小型 BP 神经网络**组成的集成模型。

这是一个样本规模相对有限的机器学习实践。根据现有数据集上的 **5 折交叉验证**，四测量模型的均方根误差（RMSE）约为 **3.3 个体脂率百分点**，表明它在当前数据范围内具有一定的估算能力。不过，这属于**内部验证**，并不意味着对每个人都同样准确，也不代表已经通过中国人群的独立外部验证。

## 适用范围与局限

- **适用人群：** 18–59 岁、非孕女性；其他人群（如男性、未成年人、孕妇及 60 岁以上女性）不适用当前模型。
- **估计而非实测：** 网页给出的是基于既有样本训练出的预测值，不是实际测得的体脂率。
- **误差因人而异：** 不同体型和人群的预测误差可能不同。页面展示的经验误差范围不等于对某位用户个人结果的保证。
- **数据代表性有限：** 训练数据来自美国调查样本，尚未在中国成年女性群体中完成充分的外部验证。
- **测量方法会影响结果：** 腰围、臀围量错部位，以及使用不同的测量条件，都可能引入额外偏差。

因此，本工具更适合帮助用户**粗略了解体脂率可能处于什么范围**，不适合据此做精确分级、疾病判断或治疗决策。

## 隐私与运行方式

当前版本采用**纯前端计算**：神经网络参数和计算逻辑包含在网页文件中，输入的身体测量值在用户自己的浏览器内参与计算，不会被网页主动上传至服务器；目前也没有账号登录或云端健康档案功能。

网站代码托管和访问平台自身可能记录常规访问日志，这与上传个人体测数据是两回事。

## 项目性质

这是一个**课程作业的延伸实践**，目的是尝试把课堂中学习的建模方法变成一个真正容易使用的小工具。

项目仍处于早期阶段。后续可能继续研究不同人群中的模型误差、扩充验证数据，以及更方便的个人体测记录方式，但当前版本不会提供医疗诊断功能。
